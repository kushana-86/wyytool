# wyytool · NCM 转 FLAC

Windows 拖入式音乐转换工具：批量转换 NCM，提取封面、歌词及歌曲信息。

**完整安装、使用和目录说明见 [read.md](read.md)。**

1. 安装 Python 3.10+，下载并解压本仓库。
2. 把 NCM 文件或文件夹拖到 `拖入转换.bat`。
3. 从 `output` 中取出 FLAC 和同名 LRC，复制到支持 FLAC 的播放器。

也可以将歌曲放入 `download` 后双击启动器。老播放器请使用 `拖入转换_播放器兼容版.bat`。

原 FLAC 默认保留音频数据；有损音频转成 FLAC 不会改善音质。歌词和封面是否可获取取决于文件内容及网络接口。

仓库只包含代码、文档和测试；歌曲及转换结果仅保存在本地。
